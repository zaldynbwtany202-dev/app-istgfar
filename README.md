# وسن · Wasan 4.5

**رفيقك اليومي للصلاة والقرآن والذكر** — تطبيق أندرويد يعمل دون إنترنت ودون إعلانات.

## ما الجديد في 4.5 · إصدار «المصحف والسمات»

- **سمات جديدة:** ناعمة وردية (وردي ناعم، ليل وردي، لافندر، خوخي، ذهبي وردي، بنفسجي حالم) ومختلفة (ليل حالك، فجر، بحري، زيتوني، قهوة، رمال، ناصع)، مع **لون من اختيارك** و**حجم خط التطبيق**.
- **أكثر من 230 قارئًا** (mp3quran.net): سورة كاملة مع متابعة الآية وتكرارها، و**تنزيل السور** للاستماع دون إنترنت، و**مؤقّت النوم**.
- **أصوات الطبيعة أثناء القراءة:** أمواج، مطر، عصافير، نسيم، جدول، ليل هادئ — تهدأ وحدها عند التلاوة.
- **المصحف:** خطّان (مصحف المدينة · أميري قرآن)، تسع خلفيات، تباعد الأسطر والمحاذاة، تخفيف السطوع، القراءة الكاملة، التمرير التلقائي، مواضع السجود، وضع الحفظ «ما بعد أول كلمة».
- **التظليل والتدبّر:** خمسة ألوان لتظليل الآيات، وملاحظة تدبّر لكل آية، وقسم «المحفوظات» يجمعها.
- **إصلاح:** الآية التي يُفتح عليها المصحف (من العلامات أو البحث أو «تابع القراءة») كانت تظهر أحيانًا كلمةً في كل سطر.

## المزايا

مواقيت دقيقة بطرق حساب متعددة · الأذان كاملًا بصوت مؤذّن حقيقي · مصحف كامل بالرسم العثماني مع التلاوة والبحث والختمة ووضع الحفظ · أذكار من «حصن المسلم» · القبلة · المسبحة · التقويم الهجري · رمضان يومًا بيوم · قضاء الفوائت · العادات والمهام · بستان بألف مستوى وأوسمة · نسخ احتياطي واستعادة.

## البناء من المصدر

يُبنى المشروع دون Gradle بسكربت واحد:

```
python fetch_deps.py      # مرة واحدة: تنزيل مكتبات AndroidX إلى .deps
python build_apk.py all   # aapt2 → kotlinc → d8 → zipalign → apksigner
```

يحتاج: Android SDK (build-tools 34 وplatform android-34) وJDK 21 وKotlin 1.9.22 — تُضبط المسارات بمتغيرات البيئة `WASAN_SDK` و`WASAN_JAVA` و`WASAN_KOTLIN_LIB`.

**مفتاح التوقيع غير مرفوع** لأن المستودع عام — انظر [signing/README.md](signing/README.md).

## هيكل المشروع

- `app/src/main/assets/www/` — الواجهة كاملة (HTML · CSS · JS)، ومنها `js/reciters.js` (مكتبة القرّاء) و`js/ambient.js` و`snd/` (أصوات الطبيعة).
- `app/src/main/java/com/app/` — النواة الأصلية (Kotlin): الأذان، الموقع، الأدوات، التلاوة، تنزيل السور.
- `app/src/main/res/raw/` — تسجيلات الأذان ونغمة وسن.
- `README.txt` — سجلّ التغييرات المفصّل لكل إصدار.
