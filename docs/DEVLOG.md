### ❌ أخطاء ومشاكل (وطرق حلّها)
1. **`pip install androguard` فشل** — بسبب حماية النظام PEP 668.
   → الحل: استخدام `--break-system-packages`.
2. **مكتبة `axmlparserpy` معطوبة على Python 3** — تستورد وحدات بأسلوب Python 2 (`import bytecode`).
   → الحل: الاستغناء عنها وكتابة الأداة الخاصة `tools/axml_dump.py`.
3. **تحذير حجم المستودع:** ملف WeMuslim وحده 78 م.ب. المستودع يقترب من حدود الحجم العملية.
   → قرار: لا نفكّ ضغط التطبيقات الكبيرة إلى ملفات مفردة داخل Git (يكفي الـ APK + وثائق التحليل)، وسننظر في Git LFS إن وصلتنا ملفات كبيرة أخرى.
   → ملاحظة: لا تتوفر Java في البيئة حاليًا، يلزم تثبيتها لاحقًا لتشغيل `jadx` لفك ترجمة الـ dex.
